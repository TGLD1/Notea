# Site des applications FASTEK

Site statique (HTML/CSS) hébergé sur Netlify : catalogue des applications, page de téléchargement de Notea et pages légales.

- Déploiement : Netlify, dépôt `TGLD1/Notea`, répertoire de base `site-apps`, répertoire de publication `.`, aucune commande de build.
- Téléchargement : le bouton pointe vers `https://github.com/TGLD1/Notea/releases/latest/download/Notea.apk` ; la version affichée est lue sur la dernière release GitHub.
