Notea

Le suivi scolaire, simplement

L'application

Notea est une application Android de suivi scolaire pour les élèves béninois : notes, moyennes, objectifs, simulateurs, planning avec rappels et bulletin au format PDF. Elle fonctionne hors ligne et sans compte.
